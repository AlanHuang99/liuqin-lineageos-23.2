## Corrected Google-apps advice

The July images use read-only EROFS filesystems. The earlier MindTheGapps sideload instruction is withdrawn because the examined installer requires writable system mounts. Reserved space alone does not change this. Use the built-in-GApps variant when Google services are required; migration from an already configured vanilla installation has not been validated.

An earlier local GApps build used the same July version label as the public vanilla build. Their timestamps and package contents differ. Identify the current variant before choosing an update.

## Historical validation

The original July checks established boot, enforcing SELinux, file-based encryption, display modes, rotation, Wi-Fi scanning, Bluetooth enablement, photo capture and recovery sideload availability. Later automated baseline tests reproduced microphone capture and rotated keyboard-mapping failures. Those results and the maintenance changes are recorded in the [release notes](RELEASE_NOTES.md).

The NFC/SecureElement guards remain in the maintenance source. The archived `liuqin_no_se` module addresses older installations without those guards; it is not an update mechanism.

July's initial-install instructions include data formatting. Existing installations should follow the [same-variant upgrade guide](UPGRADE.md), which does not format data. Keep images associated with their own release and variant.
